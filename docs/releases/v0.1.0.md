# ActualForge 0.1.0

Released: 2026-10-02

ActualForge 0.1.0 is the first independent release and is based on **Actual Budget v26.9.0** at commit `59fe126f637d858c061e1eeedbef5436c8f2225a`.

## Highlights

- Contracts with recurrence, price history and transaction links.
- Payment chains for debit attempts, reversals, retries, settlements and fees.
- Reversible transaction splits.
- Internal transfer matching and credit-card settlement cycles.
- Forecasts combining Actual schedules, contracts, open payment chains, credit-card settlements and manual payments.
- Central clarification cases for uncertain interpretations and durable contract amount changes.
- Original Actual transactions remain authoritative.

## Deployment

```bash
cp .env.release.example .env
docker compose -f compose.release.yaml pull
docker compose -f compose.release.yaml up -d
```

Images:

```text
ghcr.io/tojollinor/actualforge:0.1.0
ghcr.io/tojollinor/actualforge-finance-engine:0.1.0
```
